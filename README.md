# Pixel Party

Pixel Party is a static browser-game hub built with HTML, CSS, and JavaScript.

## Included

- Blast Rivals
- Grandma's Cookie Counter
- Jet Ski Race
- Cannonfall // Last Stand
- Pixel Dodge
- Flip Match
- A localStorage points wallet and points shop

The project is designed to publish directly on GitHub Pages. No frameworks, build tools, or backend are required.
